## Quick Overview
AI WeatherWise is a Node.js/Express/MongoDB backend that delivers real-time weather data enriched with Google Gemini AI-generated summaries and personalized recommendations, secured with JWT authentication.

Actual working source code should be added under a `/src` (or similar) folder alongside these phase folders, as built in Phase 5.
